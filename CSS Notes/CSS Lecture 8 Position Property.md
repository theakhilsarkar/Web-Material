## 🔥 Quick Summary Table

| Position | Purpose                      | Flow | Scroll Behavior |
| -------- | ---------------------------- | ---- | --------------- |
| static   | Default layout               | Yes  | Normal          |
| relative | Move from original spot      | Yes  | Normal          |
| absolute | Exact position inside parent | No   | Normal          |
| fixed    | Lock to screen               | No   | Stays fixed     |
| sticky   | Stick on scroll              | Yes  | Becomes fixed   |

---

## 💡 When to Use What?

* Use **relative** → small adjustments
* Use **absolute** → inside card, tooltip, badge
* Use **fixed** → navbar, floating button
* Use **sticky** → section headers, menus
