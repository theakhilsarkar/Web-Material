**Project Title:** React Blog Management App (Redux Toolkit)

**Project Duration:** 1 Day

**Project Description:**

In this one-day project, students will build a simple yet functional **Blog Management Application** using **React JS** and **Redux Toolkit**. The goal of this project is to help students understand real-world state management and how to efficiently handle data flow in a React application.

Students will create a blog system where users can perform complete **CRUD operations (Create, Read, Update, Delete)** on blog posts. Each blog will contain essential fields such as **title, description, category, and date**.

The application will use **Redux Toolkit** to manage global state, ensuring clean, scalable, and organized code. Students will learn how to create slices, actions, reducers, and integrate the Redux store with React components.

**Key Features to Implement:**

* **Add Blog:** Create a new blog post with required details
* **View Blogs:** Display all blogs in a structured list or card layout
* **Edit Blog:** Update existing blog details
* **Delete Blog:** Remove a blog from the list
* **Search Functionality:** Search blogs based on title or keywords
* **Filter Blogs:** Filter blogs based on category or date
* **State Management:** Use Redux Toolkit for handling all blog data

**Technical Requirements:**

* Use **React Functional Components** with Hooks
* Implement **Redux Toolkit (createSlice, configureStore)**
* Use **React-Redux (useSelector, useDispatch)**
* Maintain proper folder structure (components, redux, pages)
* Ensure clean UI and user-friendly experience

**Learning Outcomes:**

* Understand the concept of centralized state management
* Gain hands-on experience with Redux Toolkit
* Learn CRUD operations in a real-world scenario
* Improve problem-solving and component structuring skills
* Implement search and filtering logic efficiently

This project is designed to be completed within a single day while covering important industry-level concepts in a simplified manner.
