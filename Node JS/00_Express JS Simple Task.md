**Project Title:** Customer Management System (CRUD)

**Task:**
Build a backend application using Node.js, Express, and MongoDB to manage customer data.

**Requirements:**

* Add a new customer (name, email required)
* View all customers
* View single customer by ID
* Update customer details
* Delete a customer

**API Routes:**

* POST /customers
* GET /customers
* GET /customers/:id
* PUT /customers/:id
* DELETE /customers/:id

**Conditions:**

* Use MongoDB with Mongoose
* Follow proper project structure
* Handle errors and validations

**Output:**
Working REST API with all CRUD operations functioning correctly.
