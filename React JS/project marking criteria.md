Common Marking Scheme (Total 50 Marks with Jury Criteria)

1. Role-Based Authentication – 5 Marks
   0–1: Login not working or no role separation
   2–3: Basic login with partial role handling
   4–5: Proper role-based access (Admin, Manager, Employee) with secure flow

2. Employee Management (CRUD) – 5 Marks
   0–1: Incomplete or errors in operations
   2–3: Basic add/update/delete working
   4–5: Full CRUD with validation and proper data handling

3. Attendance System – 5 Marks
   0–1: Not implemented or incorrect logic
   2–3: Basic check-in/out without accuracy
   4–5: Proper time tracking with correct hour calculation

4. Payroll & Salary Calculation – 8 Marks
   0–2: Incorrect or missing salary logic
   3–5: Basic calculation but missing rules
   6–8: Accurate hourly calculation with deductions and rules applied

5. Leave Management – 5 Marks
   0–1: Not implemented
   2–3: Apply leave only
   4–5: Proper leave rules (1 paid leave, extra deduction, handling)

6. Business Logic Accuracy – 7 Marks
   0–2: Incorrect calculations (hours, salary, leave)
   3–5: Partially correct logic
   6–7: Fully correct logic (working hours, Sunday exclusion, deductions)

7. UI/UX and System Design – 5 Marks
   0–1: Poor UI, difficult to use
   2–3: Basic usable interface
   4–5: Clean, structured, easy navigation

8. Extra Features – 5 Marks
   0–1: No extra features
   2–3: Basic additions (search/filter)
   4–5: Advanced features (salary slip, reports, structured code)

9. Presentation & Demo – 5 Marks
   0–1: Poor explanation, no clarity
   2–3: Average explanation with basic demo
   4–5: Clear explanation, confident delivery, smooth live demo

Total: 50 Marks
